# Сайт-лендинг ООО «ДЕЯ»

Элегантный одностраничный корпоративный сайт Общества с ограниченной ответственностью «ДЕЯ» (ИНН 1684028571). Учредитель и генеральный директор — Овчинников Андрей Александрович.

## Файлы

| Файл         | Назначение                                   |
|--------------|----------------------------------------------|
| `index.html` | Главная страница (разметка всех разделов)    |
| `styles.css` | Оформление, адаптивность, анимации           |
| `script.js`  | Меню, эффекты при прокрутке, год в футере    |
| `favicon.svg`| Значок сайта (монограмма «Д»)                |

Внешних зависимостей нет: используются только шрифты Google Fonts, подключённые через CDN, поэтому сайт работает даже при простом открытии `index.html` в браузере.

## Публикация на GitHub Pages

1. Создайте репозиторий, например `deya-site`.
2. Загрузите в корень репозитория все четыре файла (`index.html`, `styles.css`, `script.js`, `favicon.svg`).
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите источник **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/deya-site/`.
